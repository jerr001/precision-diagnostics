# Precision Diagnostics

Premium Nigerian medical laboratory and diagnostic centre demo built with:

- HTML5
- CSS3
- Vanilla JavaScript

## Structure

medical-laboratory/
- index.html
- css/style.css
- js/script.js
- assets/images/

## Run

Open `index.html` in a browser, or use VS Code Live Server.

## Notes

This is a frontend demonstration. Forms do not send real data and the patient results portal is not connected to a live laboratory information system.

The fictional business details, statistics, package prices, testimonials and imagery are for presentation purposes.

All interactive features are implemented in vanilla JavaScript.
